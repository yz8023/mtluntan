# MT论坛 客户端 (MT Luntan)

第三方 Android 客户端，用于浏览论坛 `https://bbs.binmt.cc`（Discuz + Comiis 模板）。

> 声明：本项目为个人学习用途的第三方客户端，与论坛官方无关。请遵守站点规则，合理使用。

## 功能

### 浏览与阅读

- 导读：最新 / 新增 / 热门 / 精华（默认视图可在设置里改）
- 社区：板块分类浏览、帖子列表
- 帖子详情：PC / 移动模板解析、分页浏览（本页没有回复而后面还有页时**自动续页**）、图片 / 代码 / 引用 BBCode 渲染
  - 代码块、引用块折叠 + 单独复制；楼层菜单支持复制正文 / BBCode / 带楼层署名 / 只复制代码
  - 正文图片原位全宽显示，点开可双指缩放、左右切换
  - 隐藏内容（回复可见）原位展开；点赞名单可查
  - 阅读进度记录到「第几楼 / 第几页」，再次进帖可「继续阅读」
  - 离线快照：断网时自动回落本地保存的页面；支持导出 HTML / 纯文本
  - 附件下载（金币附件先确认再扣费）
- 发帖 / 回复 / 编辑：BBCode 工具栏 21 个预设标签、取色器、渐变字、实时预览、常用语、草稿自动暂存、插图上传（自动压缩 ≤900 KB）
- 消息：通知（长文可展开看全文）+ 私信气泡对话；未读状态按账号隔离，切号即时同步，底栏消息角标随未读数走
- 搜索：站内帖子搜索；TID / UID 快速跳转（支持直接粘链接）
- 社交：用户主页、好友列表、关注 / 取关、黑名单、积分明细
- 签到（k_misign 插件）：每日定时自动签到（默认 08:30，可改）、一键全部签到、
  按账号保存签到天数 / 排名 / 奖励，账号之间默认间隔 5 秒防 403
- 账号管理：多账号、WebView 登录导入会话（登录后由服务端个人页确认身份，绝不从 Cookie 名猜用户名）、
  也可「用 Cookie 添加账号」手动导入、账号隔离 cookie、
  密码托管（Android KeyStore AES-GCM）、会话自愈（掉线用托管密码静默重登）
- 本地数据：浏览历史、草稿箱、收藏、离线帖子、记录中心（解锁决策 / 加载耗时 / 运行日志）
- AI 助手：任意 OpenAI 兼容接口，对话、总结帖子、自动回复解锁「回复可见」（支持演练模式与每日上限）
- 外观与主题引擎：深色模式、**12 套主题色 + 自定义种子色**（按色轮生成整套 ColorScheme）、配色深浅滑杆、
  玻璃强度三档（关 / 柔 / 强）、动态取色、面板不透明度、字体缩放、底栏滚动自动隐藏、点当前 Tab 刷新
- 交互动效：按压缩放、失败震动反馈、底栏图标呼吸、列表交错入场、极光背景、胶囊液态底栏（参考 yz8023/ui），
  动效总开关 + 阻尼滑杆，关闭时直接渲染最终状态
- 自动通过 WAF 验证（acw_sc__v2，纯 Kotlin 实现）

## 技术栈

- Kotlin + Jetpack Compose (Material 3)
- Room（账号 / 历史 / 草稿 / 收藏 / 阅读进度 / 帖子缓存）
- DataStore（设置）
- OkHttp + jsoup（网络 / 解析）
- Rhino（WAF 挑战脚本执行）
- WorkManager（定时签到）
- Coil（图片加载）

## 构建

环境要求：JDK 17、Android SDK（minSdk 26 / target 34）、Android Gradle Plugin 8.x。

```bash
# 拷贝 SDK 路径（可选，也可用环境变量 ANDROID_HOME）
echo "sdk.dir=/path/to/android-sdk" > local.properties

# debug 包
./gradlew :app:assembleDebug

# 正式包（在 keystore.properties 指向你的 keystore；仓库里没提交 keystore 时会退回 debug 签名）
./gradlew :app:assembleRelease

# 单测
./gradlew :app:testDebugUnitTest
```

产出 APK 位于 `app/build/outputs/apk/`。
