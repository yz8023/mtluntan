# mtluntan 1.1.1 更新说明

> 本版针对你反馈的 4 个问题逐条修复，构建 + 打包全部在本地沙箱完成（未使用 GitHub Actions）。

## 1. 点「添加账号」进到的还是上一个已登录的账号
**根因**：登录页用的是系统 WebView，而 WebView 的 Cookie 是**全局共享**的——上次登录留下的会话还在，
一打开就是「已登录」状态，于是旧的导入逻辑又把同一个会话导入了一遍；再加上账号身份是从 Cookie 名猜的，
就出现了「加不了新账号 / 加了却还是原来那个」。

**修复**：
- 进入添加账号页时**先清空 WebView 的 Cookie**，从真正未登录的登录页开始；顶栏还提供「清空网页会话并重新登录」一键重来；
- 拿到会话后先用 `*_auth` 指纹（同一设备同一账号稳定不变）在本地账号里比对：
  - 已存在 → **只刷新它的会话**，不新增、不覆盖（并提示「这个账号已在列表里」）；
  - 不存在 → 临时会话请求个人页，由**服务端确认真实 uid / 用户名 / 昵称 / 头像**后入库；
- 识别不到身份时不再瞎猜用户名，而是弹出「给这个账号起个名字」对话框（也可以走「用 Cookie 添加」）；
- 页面顶部直接显示「已添加 N 个账号：…」，添加按钮拆成显式的两个：「添加账号」「用 Cookie 添加」。

## 2. 已登录账号没有管理（删除 / 编辑）
- 账号卡片新增 **编辑**：改昵称（显示名）、UID、头像地址 —— 之前只有一个删除图标；
- 删除改成带文字的按钮（红色图标 + 「删除」），确认框里明确写出「只删本机会话，其他账号与论坛账号不受影响」；
- 卡片头像在没有头像地址时回落到 `uid` 头像，不再是一块空白；
- 操作行支持横向滚动，窄屏也能点到全部操作。

## 3. 卡片一层方框底色 / 帖子标题不对齐
- **底色**：`MtCard` 默认不再铺底色、不描边（只在按下时缩放反馈），列表改用一条很淡的分隔线分条
  （颜色取主题的 `outlineVariant`，换主题自动跟着变）。消息列表、私信、账号、我的、记录中心、帖子楼层
  全部统一到这套「无底色卡片」。
- **对齐**：帖子列表项改成「固定 76dp 缩略图槽位 + 内容」两列结构——
  - 带图帖显示图片（多图右下角带「图 N」角标），
  - 纯文字帖显示同尺寸的占位块（描一个「文字帖」图标），
  - 因为槽位尺寸一致，**所有卡片的标题都从同一条竖线开始**，纯文字帖与带图帖混排不再错位；
  - 摘要最多两行、元信息一行，卡片高度稳定，滑动时不会上下跳。

## 4. 回复：点输入框直接半屏编辑器，并去掉输入框上方的翻页栏
- 底部不再放输入框，只留一条「写回复…」胶囊入口；点一下**立刻弹出半屏回复面板**，键盘自动聚焦；
- 面板里就是完整编辑器能力：BBCode 工具条（加粗 / 颜色 / 渐变字 / 标签 / …）、快捷短语、发送按钮，
  右上角还有「完整编辑器」入口（需要插图 / 实时预览时用）；
- 工具条抽成公共组件 `ui/components/BbcToolbar.kt`，编辑页与回复面板**共用同一套**，行为一致；
- **输入框上方那条「首页 / 上一页 / 下一页 / 末页」整条去掉**；翻页挪到列表底部的页脚（「上一页 · 第 x / y 页 · 下一页」），
  看帖时就在眼前，也不再挡着输入区。
