# mtluntan 1.1.4 更新说明

> 本版按你这次的四条反馈重做：**消息部分**、**正文与评论区排版**、**账号名字识别**、**卡片白色底色**。
> 只发 release 安装包；构建在本地沙箱完成。

## 1. 消息部分重做（参考 mt-lun-tan 的 `fragment_notice.xml` + `NoticeFragment`）
你参考的项目里，消息页是「**一张圆角卡片装六个入口**」，我按同样的结构重做：

| 入口 | 副标题 | 进入 |
|---|---|---|
| 我的消息 | 私信与对话 | 私信会话列表（原生，点进去是聊天页） |
| 我的粉丝 | 关注你的人 | 粉丝列表（点头像进个人空间） |
| 我的帖子 | 有人回复了你的帖子 | 通知分类 `view=mypost` |
| 坛友互动 | 评论、点赞与 @ 提醒 | 通知分类 `view=interactive` |
| 系统提醒 | 系统通知与审核结果 | 通知分类 `view=system` |
| 应用提醒 | 版本更新与公告 | 通知分类 `view=app` |

细节：
- 每行 = **38dp 语义色圆底图标**（私信蓝 / 粉丝粉 / 帖子绿 / 互动橙 / 系统紫 / 应用青）+ 标题 + 副标题 + **未读角标** + 右箭头 + **按压缩放反馈**；
- 行与行之间是缩进 62dp 的 0.5dp 细分隔线（原来是一堆方框卡片，现在是干净的一整张）；
- **六类并发拉取**（串行会明显变慢），顶栏「全部已读」会同时通知服务端；
- **未读口径**：通知类取服务端标记为未读的条数；私信取未读会话数；
  **我的粉丝取「上次查看之后新增的人数」**（本地快照比对，看过即归零）——和你参考项目里 NoticeBadgeManager 的做法一致；
- 所有列表都是原生 Compose 渲染，不套 WebView。

## 2. 正文与评论区排版（参考 `thread_detail_activity.xml` + `item_reply.xml`）
- **楼主正文**：改成参考项目那种「**不套卡片壳**」的排版 —— 发布者行（40dp 头像 + 加粗名字 + 用户组小徽标 + 时间）→ 细分隔线 → 正文 → 「复制正文」胶囊 + 操作行；
- **评论区**：每条评论是**独立的嵌套卡片**（半透明底色 + 1dp 描边 + 12dp 圆角，和参考项目 `reply_nested_bg` 一致），头像 36dp、`#楼层` 前缀、名字加粗、**楼主徽标**、内容整体缩进 45dp；
- **引用**是暖色小卡片（参考项目 `reply_quote_bg`），带「回复原文」标题；
- 新增**评论区标题栏「全部回复 + 数量」**，右边是 **只看楼主** 开关与 **正序/倒序** 切换（纯本地过滤与排序，不发请求）；
- 上一版的中间渐变头带、左侧竖色条都去掉了 —— 现在「正文无壳、评论有壳」，一眼可分。

## 3. 账号名字识别（参考项目 `ForumParser.parseUserProfile`）
你说「名字识别错、得手动改」，这次把识别做成**多级候选 + 严格校验**，任何一级不合格就继续找下一级：

1. **头像容器里找名字** —— 结构最稳：不管站点换成哪个 class，名字就在头像旁边（往上找 4 层，跳过等级/用户组/时间/统计这类元素）；
2. **选择器优先级**：`.comiis_space_tx h2` → `h2.fyy` → `.comiis_space_name` → `.comiis_me_name` → `.mt_username` → `.username` → `.user_name` → `.profile_name` → `h1`…；
3. **页面明文「欢迎您回来，xxx」**（登录校验页只有这一处有名字）；
4. 最后才是带 `space-uid` 的链接文字。

校验规则：长度 1–24、不能纯数字、不能含「论坛 / 登录 / 用户组 / 等级 / 帖子 / 主题 / 积分 / 手机版」等噪声词、不能含中文标点（多半是拼进来的句子）。
另外 **uid 兜底**新增两条：`li:contains(用户ID) .profile_rs`、以及**从头像地址 `avatar.php?uid=123` 反推**。
自动识别失败时不再静默存个错名字：账号密码登录会退回「你输入的登录名」并在提示里说明，账号卡片上的「编辑」可以随时改本地显示名，「检测会话」会重新拉一次并覆盖。

## 4. 卡片内部的白色底色（这是主题的问题，已从根上修）
根因在配色生成器：**浅色模式下「容器色」是从近白色的 `#F2F4F8` 混出来的**，浓度调低时几乎就是纯白；而 `surfaceVariant` 还额外掺了 45% 白色 —— 所以卡片里（代码块、引用、聊天气泡、底栏、工具条）到处都是白底。
现在：
- 容器色 = **主题色染出来**（浅色 16%–36% 浓度，深色 20%–34%），和背景明显分层但绝不是白色；
- `surfaceVariant`、`surfaceContainerLow/Lowest` 不再掺白；`surfaceContainerLowest` 直接等于背景；
- 新增统一的**嵌套卡片表面**（半透明 + 1dp 描边），评论、引用、消息卡片全部走它。
如果你喜欢更浓/更淡，设置里的「浓度」滑杆照样能调，但不会再出现白色。
