- **版本**：1.1.5（versionCode 7）
- **安装包**：`mtluntan-1.1.5-release-debugsigned.apk`
- **大小**：3,725,937 字节
- **SHA-256**：`6d94f93aab737ec3ddaa5d3ee8f1da109c6210938a065dea05220a78b625289b`
- **测试**：19 个单元测试全绿（ParserTest 14 + WafChallengeSolverTest 5，0 失败）

本轮修的 5 个问题，逐条对应：

## 1. 点「消息」不自动加载、显示异常，要手点刷新

**根因**：进页面时会判断「当前账号」，而账号是启动时**异步恢复**的：
数据存储里的账号名先就绪，会话（cookie / SessionHolder）后切换。
于是第一屏的六个请求全都是**游客身份**发出 → 返回空/异常；等恢复完成后再点刷新才正常。
另外原来的 `LaunchedEffect(generation, activeAccount)` 把 `activeAccount` 当 key，
账号从 `null` 变成名字的那一刻会**取消掉**正在进行的这次加载，首屏就永远停在异常态。

**修复**：
- `awaitActiveAccount()` 现在无条件等「账号恢复闸门」，并且**确认会话已切到该账号**，没切就补切一次（`AuthRepository.kt`）；恢复流程用了兜底触发，进程被系统重启后直接从消息页冷启动也不会卡。
- 消息页/通知列表/粉丝页统一改为：进入必有一次加载 + 账号就绪后防抖补一次（不再互相取消），并用互斥锁串行化，避免两次请求打架。
- 首屏失败会自动重试一次，不用再手点刷新。

## 2. 评论区图片显示异常（参考 qcxs/mtbbs_app 完善）

**根因**：旧的图片渲染是 `fillMaxWidth()` 拉满宽度，小图被放大成马赛克、宽高还被写死，比例全错；
另外 BBCode 里 `[img]//域名/路径[/img]`、`[img]data/attachment/...[/img]` 这两种常见写法会被**漏成一段文字**（图片根本没显示）。

**修复**（新增 `ui/components/PostImage.kt`，正文与评论共用）：
- 宽度上限 = min(原图宽度, 可用宽度)，**小图绝不放大**；高度按原图比例，超过 600dp 才截断；
- 加载中显示占位（转圈），失败显示「图片加载失败，点这里重试」并可点击重试，不再是一片空白；
- 点击看大图（原图廊）、长按复制图片链接；
- 解析侧补齐 `//` 协议相对地址与相对路径（`BbcBlocks.kt`），并新增 3 个单元测试覆盖这三种写法。

帖子内排版同步对齐参考项目：楼主标签、楼层、时间、引用原文、支持/回复动作行、图廊。

## 3. 社区可自定义显示项目 + 排版方式，并记住选择

社区页右上角新增「自定义」按钮，弹出面板三块：
- **排版方式**：文字纵列 / 图标横排（图标在左）/ 图标纵排（每行 3 个图标网格）；
- **显示项目**：眼睛图标逐个显示/隐藏版块（隐藏的立刻从列表消失），空状态给出恢复提示；
- **排序**：上/下箭头调整版块顺序，另有「恢复默认」一键还原。

所有选择写入 DataStore（`community_layout` / `community_hidden` / `community_order`），下次打开原样恢复。

## 4. 评论区无法自动拼接下一页

**根因**：拼接的可用性判断只认 `totalPages`，而移动版页面经常解析不出总页数（值为 1），
于是「下一页」一直是禁用态，自动拼接也永远不会触发。

**修复**：
- 列表滚到末尾自动拼接下一页（去抖 250ms），拼接后继续滚还能继续接；
- 判断依据改为「实际还有没有新楼层」：某页没有新楼层才认定到底，并记住状态不重复请求；
- 失败（网络错误）不推进页码，可重试；拼接会提示「已拼接第 N 页（+M 楼）」，不会静默失败。

## 5. 账号管理界面排版重构

- 顶部换成**账号总览卡**：共 N 个账号 / 启用数 / 今日已签数 / 当前账号，下面是「一键签到」「签到记录」两个等宽主按钮；
- 账号卡重排：52dp 头像（当前账号有主色描边）+ 名字 + 彩色小标签（当前使用 / 已停用 / 可能掉线 / 已托管密码 / 今日已签），右侧开关 + 「⋮」菜单；
- 信息区改为**两列网格**（账号、UID/用户组、签到状态、连续/排名），积分为可点开展开的独立条，不再是一长串灰色小字；
- 操作区只留高频两个按钮（切换为当前/检测会话、立即签到），编辑资料、托管密码、上移、下移、删除收进「⋮」菜单，界面干净很多。
